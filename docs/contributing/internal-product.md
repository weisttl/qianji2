# 千机 · 国泰海通内部工作平台

千机使用统一的产品名称、界面主题、应用标识和运行协议。产品代码、CLI、环境变量、缓存、Cookie、扩展清单和数据目录统一使用 `qianji` / `Qianji` / `QIANJI`。

## 本地启动

```bash
bun install
node scripts/prepareQianjicore.js
bun run webui
```

本地默认访问 `http://127.0.0.1:25809`，登录信息打印在启动终端。开发数据目录为 `~/.qianji-web-dev`，生产模式为 `~/.qianji-web`；可用 `--data-dir` 或 `QIANJI_DATA_DIR` 指定。

后端二进制为 `qianjicore`，引擎编号为 `qianjirs`，数据库为 `qianji-backend.db`，管家编号为 `qianji-assistant`。前后端共同使用 `QIANJI_*` 环境变量、`[[QIANJI_FILES]]` 等消息标记和 `qianji-extension.json` 扩展清单。

当前发行不提供旧名称别名、旧浏览器缓存导入或旧数据目录链接。切换到该版本时使用全新数据目录，模型、账号、助手和插件重新配置。

## 资源与构建

`packages/web-host/assets/backend.json` 记录后端版本、Rust 工具链和源码校验和。`qianjicore-source.tar.gz` 包含统一命名后的后端与引擎源码。`node scripts/prepareQianjicore.js` 从源码构建本机后端，并准备所需运行资源；不使用公共产品安装包。跨平台构建需要对应目标平台或内部准备的产品资源包。

内置技能保留文档、表格、PDF、财务建模、数据看板、流程图、业务演示与平台基础能力共 17 项。移除社交招聘、角色扮演、微信外发、OpenClaw 配置、学术论文、3D 演示、Moltbook 和公开 WebUI 部署等 10 项技能，同时移除依赖它们的 6 个内置助手，并移除 3D 游戏、个人成长教练、UI/UX 设计 3 类无关助手；内置助手保留办公、财务、数据、流程和任务规划等 12 项。管家使用 `qianji-config` 和 `qianji-troubleshooting`。

清单与离线资源由 Web 服务与服务端 CLI 运行时共用。技能更新流程见[资源维护说明](../../packages/web-host/assets/README.md)。

## 主题与业务入口

产品通过 Web 服务提供。设置仅提供 Agent、模型、技能、工具、系统、归档和关于；外观、频道配置与快捷主题切换不对用户开放。桌宠、开机启动、托盘、GPU、客户端目录迁移、内置浏览器管理及开发工具入口已移除。原外观、桌宠、客户端远程连接及 `/settings/channels` 地址均跳转至系统设置；设置弹窗同样不提供频道入口。Web 文件预览保留下载和在线编辑，不显示服务器本机文件管理器或系统应用入口。

品牌配色参考[国泰海通官网](https://www.gtht.com/)官方标识，于 2026-11-01 核对：主色 `#004E97`、辅助蓝 `#0081CC`、亮蓝 `#54C3F1`。界面派生色阶与深色模式不代表官方 VI 手册。千机图形标识由本分支绘制。

工作台提供研究材料、业务文稿、数据分析、会议纪要四类入口。点击填入草稿，由用户补充材料并发送给实际选定的模型与助手。

## 内部发行配置

`PRODUCT_CONFIG` 位于 `packages/desktop/src/common/config/constants.ts`。公开更新、遥测、原产品反馈上传和社区入口默认关闭。没有默认公共技能市场或更新下载地址；内部分发、模型和插件服务需要由管理员明确配置。

本分支尚未接入公司 SSO、组织权限、统一审计或内部模型网关。模型、插件、工具与 CLI Agent 使用实际配置的连接；界面品牌不代表已完成企业网络与权限接入。

原作者版权与第三方许可证保留，见[开源来源声明](../../packages/web-host/assets/SOURCES.md)。这些来源声明不属于运行时兼容逻辑。

## 本轮验证

助手资源采用明确的业务白名单，移除的助手不再打入运行资源包。保留助手的示例问题去掉学术论文、医疗问诊、咖啡品牌等无关内容，演示与任务规划建议改为业务材料汇报和任务执行计划。

Web 设置在电脑与手机尺寸下验证通过；外观、频道、桌宠、客户端远程连接页面不可进入。浏览器设置页面不再调用本机启动、托盘、GPU、目录迁移或开发工具接口。 PDF 使用浏览器预览；Web 代理仅对成功的 PDF 文件流允许同源嵌入，其他类型、错误响应和其他 API 保留原有嵌入策略。相关代理及 PDF 预览 23 项专项测试通过，包含 6 项新增响应头回归用例。

WebUI、独立 Web CLI、前端构建、类型检查、i18n 检查、5,019 项前端及共享测试通过（5 项跳过）。独立包以本地模拟模型验证了原生 `qianjirs` 对话请求与回复；正式本地实例以全新数据验证登录、17 项技能及原始助手清单，模型配置为空。

后端执行了全工作区测试，并对发行策略变化涉及的用例做了修正与复测。共 9,384 项通过；原有 53 项忽略用例保持忽略。一项 macOS Finder 回收站集成测试发生 AppleEvent 超时（`-1712`），未通过；未修改该用例或替代其断言，已单独复测同模块其他 366 项。此限制不影响本轮已验证的登录、配置、技能和对话流程。
